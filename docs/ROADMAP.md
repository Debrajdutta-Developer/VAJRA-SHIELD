# VAJRA-SHIELD Roadmap

## Phase 1 — Foundation
- deterministic detection
- evidence hashing
- policy preview
- forensic reporting
- local AI contract
- containerized PostgreSQL/Redis
- CI validation

## Phase 2 — Defensive Intelligence
- local inference adapter
- strict AI output schema validation
- incident persistence
- event correlation and attack timeline
- IOC/TTP knowledge graph
- alert deduplication and escalation
- signed/tamper-evident evidence ledger

## Phase 3 — Controlled Response
- endpoint/session containment adapters
- dry-run mode
- approval workflow
- rollback support
- asset-scoped policies
- rate limits and circuit breakers

## Phase 4 — Validation
- replayable attack simulations in an isolated lab
- detection benchmarks
- adversarial telemetry/prompt-injection tests
- model drift tests
- recovery/fail-safe tests
- performance and resource benchmarks

## Explicit non-goals
- retaliatory malware
- destructive payloads
- disk/SSD destruction
- unauthorized external exploitation
- unrestricted autonomous offensive operations
